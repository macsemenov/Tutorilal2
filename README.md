# Tutorial 2 — Unity

Учебная сцена для практического занятия: GameObject и компоненты, физика, материалы, UI, префабы и Instantiate.

## Как открыть

1. Откройте репозиторий как Unity-проект в Unity Hub (Unity 2022.3 LTS или новее).
2. Дождитесь импорта скриптов. При первом открытии редактор создаст сцену `Assets/Scenes/Tutorial2.unity`, куст и фруктовые префабы, материалы и UI.
3. Откройте сцену `Assets/Scenes/Tutorial2.unity` и нажмите Play.

Если автосборка не сработала, используйте меню **Tutorial 2 → Create Demo Scene**.

## Управление

- **Spawn Bush** — создаёт куст в случайной свободной точке на плоскости.
- **Spawn Fruit** — создаёт фрукты по очереди на точках ветвей уже созданных кустов. Тип фрукта циклически меняется.

Сцена и префабы создаются из примитивов Unity. Скрипты лежат в `Assets/Scripts`, генератор — в `Assets/Editor`.
