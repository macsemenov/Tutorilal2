# Tutorial 2 — Unity

Практическая сцена: интерфейс Unity, GameObject и компоненты, свойства, физика, материалы, UI, префабы и Instantiate.

## Запуск

Откройте папку `Tutorial2` в Unity Hub (проект использует Unity 6000.6). После импорта скриптов редактор автоматически создаст сцену `Assets/Scenes/Tutorial2.unity`, куст и три фруктовых префаба, материалы и UI. Затем откройте эту сцену и нажмите Play.

Если автосборка не сработала, используйте меню **Tutorial 2 → Create Demo Scene**.

## Кнопки

- **Spawn Bush** — создаёт куст из префаба в случайной свободной точке на плоскости.
- **Spawn Fruit** — по очереди создаёт яблоко, апельсин и грушу на точках ветвей кустов. Rigidbody заставляет фрукты падать на плоскость.

Куст и фрукты собраны из примитивов Unity. В префабе куста есть шесть видимых маркеров ветвей; шесть маркеров на плоскости задают места для кустов. На плоскости также установлен физический материал.

## Код

- `Tutorial2/Assets/Scripts/Tutorial2GameManager.cs` — логика Instantiate и выбор точек.
- `Tutorial2/Assets/Scripts/SpawnPoint.cs` — компонент-маркер спавна.
- `Tutorial2/Assets/Editor/Tutorial2SceneBuilder.cs` — генератор сцены, префабов и UI.
