# Tutorial 2 — Unity

Учебный проект для практического занятия: интерфейс Unity, GameObject и компоненты, свойства, физика, материалы, UI, префабы и Instantiate.

## Как открыть

1. Склонируйте репозиторий и откройте его в Unity Hub (Unity 2022.3 LTS или новее).
2. Дождитесь импорта скриптов. При первом открытии редактор автоматически создаст сцену `Assets/Scenes/Tutorial2.unity`, куст и три фруктовых префаба, материалы и UI.
3. Откройте сцену `Assets/Scenes/Tutorial2.unity` и нажмите Play.

Если автосборка не сработала, используйте меню **Tutorial 2 → Create Demo Scene**.

## Управление

- **Spawn Bush** — создаёт куст из префаба в случайной свободной точке на плоскости.
- **Spawn Fruit** — создаёт яблоко, апельсин и грушу по очереди на точках ветвей созданных кустов. Фрукты падают на плоскость благодаря Rigidbody.

Куст и фрукты собраны из примитивов Unity. Префаб куста содержит видимые маркеры точек на ветвях. Шесть объектов `BushSpawnPoint` на плоскости задают места появления кустов.

## Структура

- `Assets/Scripts/Tutorial2GameManager.cs` — логика Instantiate и циклического выбора точек.
- `Assets/Scripts/SpawnPoint.cs` — компонент-маркер точек спавна.
- `Assets/Editor/Tutorial2SceneBuilder.cs` — генератор стартовой сцены, префабов и материалов.
